# Spotify DevTools

Some separate-window features require Spotify DevTools to be enabled.

With Spicetify installed, run:

```powershell
spicetify enable-devtools
```

Restart Spotify, then try opening the Cinema Lyrics window again.
The extension's Developer Mode (Settings > Advanced) is a separate setting that
exposes debug helpers and additional logs.

For Spicetify setup, see the [official documentation](https://spicetify.app/docs/getting-started).
