Начнём

Три шага до первого куплета.

  1. Установи Spicetify для настольного Spotify.
  2. Скачай загрузчик и положи его в папку Extensions. Отключи другие версии Spicy Lyrics.
  3. Выполни команды справа. Готово — обновления загрузятся при запуске Spotify.
spicetify.app ↗
spicetify config extensions spicy-lyrics-sl.mjs
spicetify apply

Команда spicetify -c покажет путь к конфигурации. Папка Extensions находится рядом с ней.

Только настольный Spotify. Это неофициальное расширение.
